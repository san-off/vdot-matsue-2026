## 📈 VDOT Review Logic
毎月15日と末日に、Geminiコーチと共に以下の要素を評価し、VDOTを再定義する。
1. **Tペース走の安定性:** 心拍ゾーン4（170-178bpm）でのコントロール。
2. **主観的強度 (RPE):** 「脚だけ」になっていないか、全身が連動しているか。
3. **環境補正:** 向かい風10m/s以上の日は、ペースよりも「努力量」を重視。

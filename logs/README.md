## 📊 RPE (Rate of Perceived Exertion) Scale
日々のログに記録する「きつさ」の目安です。ジャック・ダニエルズ式ペース設定と照らし合わせて使用します。

| RPE | 強度レベル | トレーニングの目安 |
| :--- | :--- | :--- |
| **1-2** | 非常に楽 | リカバリージョグ、散歩程度 |
| **3-4** | 楽 | **Eペース**（ジョグ、LSD）。会話が維持できる |
| **5-6** | ややきつい | **Mペース**。集中力が必要だが長く維持できる |
| **7-8** | きつい | **Tペース**。快適なきつさ。30分程度が限界の強度 |
| **9-10** | 非常にきつい | **Iペース**（インターバル）。呼吸が激しく全力に近い |
